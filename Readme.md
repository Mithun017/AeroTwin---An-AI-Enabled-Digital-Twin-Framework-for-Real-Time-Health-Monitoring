# AeroTwin - AI-Enabled Digital Twin Framework for Real-Time Health Monitoring

> **LeakSense Twin — Cat C18 Engine Diagnostics & Real-Time Monitoring System**

AeroTwin is an AI-powered Digital Twin framework engineered for real-time health monitoring, anomaly detection, leak sensing, and predictive maintenance of industrial equipment such as the Caterpillar C18 engine.

---

## 🚀 Quick Start

### Prerequisites
- Python 3.9+
- Node.js 18+ and npm

### Running the Application

To launch both the FastAPI backend and Vite frontend dev server simultaneously, run the batch script:

```bash
.\Code\Reference_code_old_ps\Final\run.bat
```

- **Frontend Dashboard:** [http://localhost:5173](http://localhost:5173)
- **FastAPI Backend:** [http://localhost:8000](http://localhost:8000)
- **Interactive API Documentation:** [http://localhost:8000/docs](http://localhost:8000/docs)

---

## 🛠️ System Architecture

- **Backend:** FastAPI, Python, Machine Learning Inference Engines
- **Frontend:** React / Vite, WebGL / 3D Visualization, Dynamic Charts
- **Analytics & Health Monitoring:** Real-time sensor telemetry processing, fault classification, and remaining useful life (RUL) estimation.
